写文章只需要记住几条语法。下面是这个博客支持的全部常用写法。

## 标题与强调

```markdown
## 二级标题
### 三级标题
**加粗**、*斜体*、`行内代码`、~~删除线~~
```

## 列表

无序列表用 `-`，有序列表用 `1.`，任务列表用 `- [ ]`：

- [x] 已经完成的事
- [ ] 还没完成的事

## 引用与提示

> 引用用来放别人的话，或者一段想强调的结论。

!!! note "小提示"
    `!!! note "标题"` 会生成这样的提示框，适合放注意事项。

## 代码块

指定语言就能高亮：

```python
def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

```powershell
.\build.ps1            # 重新生成整站
.\serve.ps1            # 本地预览
```

## 表格

| 命令 | 作用 | 什么时候用 |
| --- | --- | --- |
| `build.ps1` | 生成 `public/` 整站 | 发布前 |
| `serve.ps1` | 本地预览 + 自动刷新 | 写作时 |
| `new-post.ps1` | 新建一篇文章 | 开新坑 |
| `organize.ps1` | 整理文件名与元信息 | 文件夹乱了 |

## 图片

图片放到 `static/images/` 里，正文里这样引用：

```markdown
![图片说明](/images/我的图片.png)
```

## 脚注

正文里可以加脚注[^1]。

[^1]: 这是脚注内容，会显示在文章底部。
