## 我在做什么

## 关于这个博客

- 所有文章都是 Markdown 纯文本，存在 `content/posts/` 里
- 没有数据库、没有第三方服务，本地一条命令生成整站
- 用了 Python + Markdown + Jinja2，风格是干净的阅读优先
